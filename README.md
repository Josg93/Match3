# Match 3
Juego de Match 3 para la materia programacion de video juegos
Donde implementamos funciones de drag and drop, powerups y funciones que reinician el tablero al quedarnos sin movimientos

# Como instalar y ejecutar:
Clona el repositorio en una carpeta directorio. luego crea un entorno virtual con:
```
python3 -m venv .venv
source .venv/bin/activate       # On Windows: .venv\Scripts\activate
```
Por ultimo instala las dependencias con el comando: (asegurate de estar en el entorno virtual):

```pip install -r requirements.txt```

Finalmente ejecuta: 
```python3 main.py```
